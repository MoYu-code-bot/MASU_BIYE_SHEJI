## 一、项目概述

### 1.1 项目名称

**火锅到家** - 火锅店综合管理系统（暂定名）

### 1.2 项目背景

为一家中型火锅店（可支持多门店扩展）构建线上化运营系统，实现门店信息展示、在线预订/点餐、订单全流程管理、以及后台运营管理。

### 1.3 技术选型

| 层级 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Spring Boot | 2.4 |
| 编程语言 | Java | 11 |
| 数据库 | MySQL | 8.0+ |
| ORM 框架 | MyBatis-Plus | 3.5+ |
| 接口规范 | RESTful API | - |
| API 文档 | Knife4j (Swagger) | - |
| 前端框架 | Vue 3 + Element Plus | （测试站可用简单前端） |
| 构建工具 | Maven | 3.9（本机已安装） |
| 缓存 | Redis | 7.0+（可选，后期引入） |

### 5.3 通用约定

- **统一响应格式**：
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

- **参数传递规范**：
  - 路径中不使用 `{id}` 形式的路径参数
  - 单参数传递使用 Query 参数（如 `GET /api/stores/detail?storeId=1`）
  - 多参数传递使用 Query 参数（如 `PUT /admin/dishes/updateStatus?dishId=1&status=0`）
  - 复杂数据提交使用 Request Body（JSON 格式）
- **分页参数**：`pageNum`、`pageSize`（默认 1 / 10）
- **排序参数**：`orderBy`、`orderDirection`（asc/desc）
- **认证方式**：JWT Token，放在 Header `Authorization: Bearer xxx`
- **错误码规范**：
  - `200` 成功
  - `400` 参数错误
  - `401` 未登录
  - `403` 无权限
  - `404` 资源不存在
  - `500` 服务器内部错误

### 5.4 Swagger 接口文档规范

#### 5.4.1 依赖与配置

- **框架**：Knife4j 3.0.3（基于 Springfox，适配 Spring Boot 2.4）
- **访问地址**：`http://localhost:8080/doc.html`（Knife4j 增强 UI）
- **Maven 依赖**：
```xml
<dependency>
    <groupId>com.github.xiaoymin</groupId>
    <artifactId>knife4j-spring-boot-starter</artifactId>
    <version>3.0.3</version>
</dependency>
```

#### 5.4.2 配置类

```java
@Configuration
@EnableOpenApi
public class SwaggerConfig {

    @Bean
    public Docket customerApi() {
        return new Docket(DocumentationType.OAS_30)
                .groupName("C端-顾客接口")
                .apiInfo(apiInfo())
                .select()
                .apis(RequestHandlerSelectors.basePackage("com.hotpot.controller.api"))
                .paths(PathSelectors.ant("/api/**"))
                .build();
    }

    @Bean
    public Docket adminApi() {
        return new Docket(DocumentationType.OAS_30)
                .groupName("B端-管理后台接口")
                .apiInfo(apiInfo())
                .select()
                .apis(RequestHandlerSelectors.basePackage("com.hotpot.controller.admin"))
                .paths(PathSelectors.ant("/admin/**"))
                .build();
    }

    private ApiInfo apiInfo() {
        return new ApiInfoBuilder()
                .title("火锅到家 - 接口文档")
                .description("火锅店综合管理系统 API 文档")
                .version("1.0.0")
                .build();
    }
}
```

#### 5.4.4 注解使用规范

所有 Controller 和接口方法必须添加 Swagger 注解：

```java
@Api(tags = "门店管理")
@RestController
```
