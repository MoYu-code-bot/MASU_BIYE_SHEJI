# 使用示例

## 示例 1：修复 KeyError

**用户输入：**
“根据我给的 CSV 修复 `KeyError: customer_segment`，不要模拟数据，输出完整 `11.py`。”

**执行要点：**
1. 读取用户提供的所有 CSV 列名。
2. 找到 `customer_segment` 对应真实列（例如 `客户分群`）。
3. 修改代码中的字段引用并删除模拟数据逻辑。
4. 运行验证，输出完整脚本与依赖清单。

## 示例 2：多表联合分析

**用户输入：**
“把客户年龄、客户职业、客户性别一起做机器学习分析并出图。”

**执行要点：**
1. 校验三张表的主键和时间粒度是否一致。
2. 进行标准化、聚类或分类建模。
3. 图片保存到用户指定目录，不擅自改路径。
4. 结果解释使用面向初学者的语言。

## 示例 3：论文规范检查

**用户输入：**
“帮我检查论文格式是否符合学院要求。”

**执行要点：**
1. 先读取 `paper_config.md`。
2. 逐项核对摘要长度、关键词数量、标题层级、参考文献格式。
3. 给出“已满足/未满足/如何改”的清单式结果。
